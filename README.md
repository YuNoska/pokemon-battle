## 対戦直前の30秒

1. **使う案と選出3匹を決める。** 案A・Bのメガ枠はグソク。案Cは基本ルカリオZかマンダの片方。ブラッキーも毎回選出しない。
2. **インテレオンがいるなら止め役を残す。** ゴリランダーのHP・草フィールド、ロトムのスカーフを確認。
3. **交代技も被弾する。** 次に出すポケモンが攻撃を受けるか考える。
4. **相手のメガ後を確認。** メガムクホークに通常マンダのいかくを入れない。
5. **積まずに倒せるなら攻撃。** 竜舞・わるだくみは毎試合の必須手順ではない。
