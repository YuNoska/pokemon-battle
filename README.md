## 対戦直前の30秒

1. **メガ枠を1匹選ぶ。** ルカリオZで特殊を通すか、ボーマンダで物理を通すか。
2. **インテレオンがいるなら止め役を残す。** ゴリランダーのHP・草フィールド、ロトムのスカーフを確認。
3. **交代技も被弾する。** 次に出すポケモンが攻撃を受けるか考える。
4. **相手のメガ後を確認。** メガムクホークに通常マンダのいかくを入れない。
5. **積まずに倒せるなら攻撃。** 竜舞・わるだくみは毎試合の必須手順ではない。

## 情報の扱い

- **原案**：共有会話の最終案をv1.0として保存。新しい推奨はv2.0。
- **確認済み**：公開ページで確認した仕様・集計日付き情報。
- **運用仮説**：このノートで補った選出や立ち回り。実戦検証はこれから。
- **計算のみ**：v2.0の速度・一部火力。実機での全丸め処理は未検証。
- **未検証**：勝率、相手の実際の型、写真で見えていない育成・持ち物。

現行案は実戦勝率で優位性が証明された構築ではありません。まず同じ構成で対戦を記録し、苦手な相手と負けた理由を見て更新します。
