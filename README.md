## 対戦直前の30秒

1. **メガ枠を1匹選ぶ。** グソクムシャで詰めるか、ボーマンダで崩すか。
2. **相手の勝ち筋を止める役を残す。** ルカリオZならロトムのスカーフ、ドラゴンならアシレーヌのHP。
3. **初手は固定しない。** ガブリアスでステロを置くより、今攻撃すべき相手がいる。
4. **相手のメガ後を確認。** メガムクホークに「いかく」「がんせきふうじ」を入れない。
5. **積まずに倒せるなら攻撃。** 剣舞は勝つための手段で、毎試合の必須手順ではない。

## 情報の扱い

- **原案**：共有会話で提案された6匹・技・能力ポイント。ゲーム内で育成済みかは未確認。
- **確認済み**：公開ページで確認した仕様・集計日付き情報。
- **運用仮説**：このノートで補った選出や立ち回り。実戦検証はこれから。
- **未検証**：勝率、詳細なダメージ乱数、相手の実際の型。

現行案は実戦勝率で優位性が証明された構築ではありません。まず同じ構成で対戦を記録し、苦手な相手と負けた理由を見て更新します。
