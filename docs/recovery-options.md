## 結論

**まずヒートロトム→カバルドンを試す。**

**ルカリオZ／ゴリランダー／アシレーヌ／ボーマンダ／カバルドン／サーフゴー**の6匹です。なまける・はねやすめ・じこさいせいを持つ3匹を用意し、対戦に出す3匹にも回復役を組み込みやすくします。ゴリランダーの先制草技とルカリオZの特殊格闘は維持します。

## カバルドンを先に足す理由

| 観点 | カバルドン | ブラッキー |
| --- | --- | --- |
| 回復 | なまけるで自分を回復 | ねがいごとで自分・味方を回復 |
| v2.0に足せる役割 | 電気無効、ステロ、物理への受け先 | ゴースト・悪への耐性、エスパー無効、味方の回復 |
| インテレオン戦 | 水弱点。対策役にはしない | ちょうはつで回復が止まる。対策役にはしない |
| 失う役割の例 | ロトムを外すと炎打点・スカーフ・ボルチェン | サーフゴーを外すと特殊の崩し・変化技耐性 |

今回カバを優先するのは、回復に加えて、v2.0にない電気無効とステロを一枠で補えるためです。ステロでタスキを崩せる場面も増えます。ただしインテレオン対面で無理にステロを置く運用には戻しません。

| 項目 | 試験設定 |
| --- | --- |
| 持ち物・特性 | ゴツゴツメット／すなおこし |
| 性格 | **わんぱく（防御が上がりやすい・特攻が上がりにくい）** |
| ポイント | HP32・防御32・特防2＝66 |
| 技 | **じしん／あくび／ステルスロック／なまける** |

物理への受け出しを増やす狙いの配分です。特定の攻撃への確定耐えは未計算。残り5匹の設定は[v2.0の育成表](current-team.md#育成設定)と同じで、持ち物重複はありません。

## 選出例

- **物理中心**：カバ＋ゴリランダー＋ルカリオZ。カバを回復しながら残し、草と特殊格闘で攻める。
- **回復を2枚出したい**：カバ＋サーフゴー＋メガ枠。カバのなまけるとサーフゴーのじこさいせいを使う。ただし相手の水打点が強い場合は固定しない。
- **インテレオンを含む前の相手**：ゴリランダー＋アシレーヌ＋ルカリオZをまず検討。カバは必須選出にしない。マンダ・グソクへの交代を見て攻撃をつなぐ。
- **カバで準備してマンダを通す**：カバ＋マンダ＋アシレーヌ。相手にインテレオンがいる場合はゴリランダーを入れる選出と比較する。

## この変更の代償

1. **メガグソクへの炎打点とスカーフの速度を失う。** 相手グソクに押される試合が増えたらロトムを戻す。回復役を増やすだけで全体が強くなるわけではない。
2. **グラスフィールド中、接地した相手へのじしんが半減。** ルカリオZを守る利点はあるが、自分のカバ・マンダの地面打点も弱まる。
3. **砂で味方も削れる。** ゴリランダー・アシレーヌ・マンダには砂ダメージ。草フィールドでの回復をそのまま純増として数えない。
4. **ふきとばしを入れる技枠がない。** みがわり・あくび無効やちょうはつを伴う積みを、カバだけで止めない。

## ブラッキーを使うなら

**ロトムの炎打点を残したい場合は、v2.0のサーフゴー→ブラッキーという別案**にします。

6匹はルカリオZ／ゴリランダー／アシレーヌ／ボーマンダ／ヒートロトム／ブラッキー。自己回復技持ちの種族数はv2.0と同じ2匹ですが、ねがいごとで他の味方にも回復を渡せます。カバ案と同時に適用するより、まず一方を試して効果を見分けます。

| 項目 | 試験設定 |
| --- | --- |
| 持ち物・特性 | たべのこし／せいしんりょく |
| 性格 | **ずぶとい（防御が上がりやすい・攻撃が上がりにくい）** |
| ポイント | HP32・防御32・特防2＝66 |
| 技 | **イカサマ／ねがいごと／まもる／あくび** |

イカサマは相手の攻撃を利用するため、自分の攻撃を下げる性格でも役割を持てます。HP202からのねがいごとの回復量は通常101が目安。翌ターンの終わりに回復するので、交代先が相手の攻撃を耐える必要があります。ブラッキー自身を回復したいときは、まもると組み合わせます。

サーフゴーを外すことで、状態異常への強さとわるだくみでの崩しを失います。ブラッキーを出す場合も、ゴリランダーやルカリオなど攻撃役を残し、回復だけで勝とうとしないこと。とくにインテレオンのちょうはつに居座らないでください。

## 試す順番

まずカバ案で10戦程度、受け出しと回復ができた回数、失った炎打点で困った相手を記録。グソク等への対応が悪化するなら、ロトムを戻してブラッキー案へ。指定サイトの採用率は参考にしつつ、自分の選出3匹で回復と攻撃が両立するかを判断します。
