# 5日ごとの非同期調査・更新方針

## 現在の基準

**2026-09-19の育成対象は[メガルカリオZ構築](team-umbreon-c.md)。** ルカリオZ／ゴリランダー／アシレーヌ／ブラッキー／ボーマンダ／ヒートロトム。ドヒドイデ構築とブラッキーA・Bは比較候補として保持します。基準は毎回READMEの「今作る構築」から読み取ります。

2026-09-18に既存の5日間隔の定期調査（ID: 5）を更新済み。同じタスクで非同期に調査を続けます。更新するのは資料で、ゲーム内の育成や登録は自動変更しません。初回確認と未読の候補は[調査メモ](../reports/2026-09-18-source-intake.md)に保存。

## 毎回読むもの

README、今作る構築、ソース一覧、対戦記録、変更履歴、直近のレポート。古い構築は `archive/` に保存し、現在の基準と混同しません。

## 調査先

1. 公式告知：実行時点のルールと適用日。
2. [バトルデータベース](https://champs.pokedb.tokyo/)：現シーズンのシングル。使用率・技・配分・同時採用。
3. [ポケ徹の構築一覧](https://yakkun.com/bbs/party/)：作品をチャンピオンズ、ルールをシングル、レギュレーションを現行に絞る。添削希望・マスター到達・最終上位の実績を区別。
4. [サックー](https://x.com/Sakku_poke)、[シグマ](https://x.com/zenchino115)、[めろ](https://x.com/Claris_bradbury)：本人の公開投稿とリンク先の記事・動画。本人プロフィール等から辿れる関連アカウントも、出所を記録して確認。
5. 海外のシングル記事・図鑑：国内の情報と比較。ダブル/VGCをシングルの流行根拠にしない。

Web取得が失敗した場合はブラウザーで閲覧可能な公開情報を確認する。それでも読めなければ未取得と記録し、投稿がない・更新がないとは断定しない。前回読めた公開投稿も全件取得済みとは扱わない。

## 採用判断と記録

- 投稿URL、確認日、投稿日、作品、シーズン、6匹、公開された型、本人が述べる実績とその確認範囲を記録。
- 過去シーズンの最終順位と、現在の途中レート・配信タイトルを区別する。人気順・Tier評価を実測勝率とみなさない。
- 現在の6匹への対策・選出・初手・危険な分岐を考察。根拠が弱い変更は候補に留め、構築を維持する。
- 意味のある変更は変更前後・理由・失う役割・未検証点・戻す条件を記載。ユーザーの育成対象を黙って別構築へ置き換えない。
- **各案に重複も省かず全6匹の性格の上昇下降・特性・全配分・持ち物・4技を掲載する。**
- 各能力最大32、合計66、4技、持ち物重複、リンクを確認。必要な火力・速度の計算条件も明記する。
- 日付付き `reports/YYYY-MM-DD.md` とCHANGELOGに差分・採用/見送り理由を残し、資料の変更をcommit・pushする。ユーザー編集は尊重する。

環境変化、構築に影響する発見、失敗、対応が必要なときに知らせます。変化がなければ静かに記録します。
