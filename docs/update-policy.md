# 5日ごとの環境調査・更新方針

[トップへ](../README.md)

## 設定

**このタスクに5日間隔の定期更新を設定済み（2026-09-15）。** 対象はポケモンチャンピオンズ・ランクバトルのシングルです。毎回、最新ルール・流行を検索して、このフォルダの資料を更新します。

更新対象は**資料上の推奨パーティー**。ゲーム内の育成やチーム登録が自動で変わる設定ではありません。

## 毎回の手順

**2026-09-18の方針変更：ドヒドイデ軸の検討は終了。所持ポケモンと敗戦報告を基にしたv2.0を基準にする。** 過去の候補ページの「優先」表記より、README・current-team.mdの新しい方針を優先する。

1. 現行チーム・変更履歴・対戦記録・前回レポートを読む。
2. 公式の対戦ルールを確認する。告知の公開日、適用日、スカウト期間を混同しない。
3. 直近のシングル使用率、同時採用、上位構築・大会記事を検索する。
4. 重要な相手構築を選び、選出・初手・勝ち筋・負ける分岐を更新する。
5. 技→配分→持ち物→メンバーの順を目安に、問題に見合った変更を比較する。
6. 根拠が十分なら現行案を更新する。元の案は `research-summary.md` に保持する。
7. 日付付きレポートと変更履歴を残す。根拠が弱ければ現行案を維持し、検証候補を記録する。

## 情報源の見方

| 情報 | 主に見るもの | 注意点 |
| --- | --- | --- |
| ルール・追加・修正 | 公式告知・ゲーム内案内 | 現在有効か、シングルか |
| 流行 | 集計日付き使用率、同時採用データ | 順位と採用割合は別。単体採用と6匹の構築採用も別 |
| 上位実績 | 公開者の構築記事、大会結果 | 日付、ルール、順位、対戦数、レンタル変更を確認 |
| 型・技・能力 | ゲーム内データ、複数の図鑑・攻略情報 | 過去作やメガ前後を混同しない |
| SNS・動画 | 具体的な構築と根拠が確認できるもの | 投稿の人気を勝率とみなさない |

ダブル/VGCのデータはシングルの流行根拠に流用しません。検索で見つかっても、対象外として分けます。

## 変更する条件

- 現行ルールでは使えない要素や、設定・説明の誤りが見つかった。
- 比較できる集計で重要な相手が増え、今の3匹選出では対処しにくい理由が具体的に説明できる。
- 対戦記録で同じ負け方が複数回起こり、立ち回りだけでは解決しにくい。
- 変更後の合法性・能力ポイント・技枠・持ち物重複・主要な素早さやダメージ基準を確認できる。

小さなサンプルや一度の連敗だけで「勝率が上がった／構築が弱い」と断定しません。数戦〜数十戦の記録は負け方の発見には使えても、優劣の証明とは分けます。

## 変更記録に必ず残すこと

| 項目 | 内容 |
| --- | --- |
| 変更前 → 変更後 | 名前、技、性格（上がりやすい能力・上がりにくい能力も併記）、全ポイント、持ち物を具体的に |
| 対象となる相手 | どの構築・型への対応を改善するか |
| 根拠 | URL、確認日、集計対象、対戦記録 |
| 失う役割 | 他の仮想敵への悪化、火力・速度・耐性の変化 |
| 検証状態 | 計算のみ／実戦済み／未検証 |
| 戻す条件 | 何が起きたら前の案に戻すか |

レポートは `reports/YYYY-MM-DD.md`、現行案は `docs/current-team.md`、立ち回りは `docs/matchups.md`、更新履歴は `CHANGELOG.md` に保存します。

環境変化・推奨変更・失敗・対応が必要なときに知らせます。変化がなければ記録だけを残します。
