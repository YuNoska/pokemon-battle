### 変更の意味

- **グソクは剣舞を待たずに攻撃。** 有利対面ではきゅうけつで回復。相手の交代を誘ったらとんぼがえり。ふいうちを外すので、居座った2ターン目以降の先制打点を失います。
- **カバは使い捨てにしない。** ステロを置いた後も、なまけるで物理の受け先を維持。ふきとばしがないため、みがわり・あくび無効の積み相手には注意。
- **アシレーヌは対面をつなぐ。** クイックターンの威力より、安全に次のポケモンを出せる場面を作ることを重視。オボンとアクアジェットを失うので、瞬間的な切り返し能力は低下します。
- **ロトムはスカーフを維持。** 回復役ではなく、炎への受け出し・高速の攻撃と交代を担当。全員を遅い耐久型にはしません。
- **マンダ・サーフゴーで最後に崩す。** 交代するだけでは勝てないので、相手の受け先が削れたら攻撃・積みに切り替えます。

## 基本選出と回し方

### 物理中心：グソク＋ロトム＋カバ

1. グソクを有利な相手に出し、であいがしら・鋼技で圧力をかける。
2. 相手の炎技が見込まれるならロトムへ。地面への交代が見えるときは、ボルトチェンジを安易に押さない。
3. ロトムへの岩技や電気技をカバで受けられる状況ならカバへ。ゴツメ・砂・ステロで削り、なまけるで残す。
4. 相手を先制技圏内に入れたら、グソクを再登場させて倒す。

**これは固定の交代順ではありません。** 相手のサブウェポンと残りHPを見て判断します。とくに水の特殊攻撃が強い相手には、この3匹を固定しないでください。

### 水・ドラゴンが重い：グソク＋ロトム＋アシレーヌ

アシレーヌで対面をつなぎ、クイックターンから攻撃役へ。ただし回復はたべのこしときゅうけつ頼みになるため、長い受け合いより短い交代戦で削り切る選出です。クイックターンより先に倒される対面では通常交代します。

### 回復しながら終盤の全抜き：マンダ＋ロトム＋サーフゴー

ロトムで相手の動きを見ながら削り、マンダのはねやすめ・サーフゴーのじこさいせいでHPを維持。相手の物理受けを特殊技で削ってからマンダで舞う。相手に強い水打点が多い場合はロトム枠をアシレーヌに替えるなど、選出を調整します。

## 相手別の注意

| 相手 | 選出の出発点 | サイクルで意識すること |
| --- | --- | --- |
| カバマンダ | アシレーヌ＋サーフゴー＋メガ枠 | カバに水技で圧力。マンダに積まれてから交代で受けようとしない |
| グソク中心 | ロトム＋カバ＋メガ枠 | 炎技を押す前に相手の水・地面への交代を考える。カバは物理受けでもきゅうけつの回復を許す |
| 雨・特殊水 | アシレーヌ＋サーフゴー＋メガ枠を検討 | この案の課題。水耐性だけで雨アタッカーを受け切れるとは考えない。頻発するなら水ロトムへの変更を次に検討 |
| ルカリオZ | ロトムを優先 | 受け回しで完封する相手ではない。スカーフを失うトリックは、速度が必要なくなってから |
| 耐久構築 | ロトム＋サーフゴー＋マンダ | トリック・わるだくみで回復の応酬を崩す |
| メガムクホーク | ロトム＋カバ＋アシレーヌなど | すでにメガした相手へ通常マンダのいかくを入れない。あまのじゃくで強化してしまう |

## 交代を増やすときの落とし穴

- **ステロに弱い**：ロトムとマンダは交代時に大きく削られる。除去役のない案なので、何周も交代する前提にはしない。
- **砂が味方も削る**：ロトム・マンダ・アシレーヌは砂ダメージを受ける。アシレーヌは砂中にたべのこしの回復が相殺される。
- **高速ボルチェンは安全着地を保証しない**：相手より先に動くと、交代先がそのターンの攻撃を受ける。逆に遅いとんぼ・クイックターンは、使う本人が攻撃を耐える必要がある。
- **いかくは毎回使えない**：ボーマンダは一度メガするとスカイスキンになる。再登場のたびにいかくを入れるサイクルではない。
- **メガ枠は基本どちらか1匹**：グソク＋マンダを機械的に同時選出しない。

## 根拠と試す順番

[海外サイトのM-Cシングル集計](https://www.pokemon-zone.com/champions/ranked-seasons/singles/)で、グソクのとんぼがえり・きゅうけつ、カバのなまける、アシレーヌのクイックターンの採用を確認。その役割を参考に組み合わせた**独自案**で、海外公開の完成構築や実績付きレンタルではありません。

まず現行から「ガブ→回復技持ちカバ」「グソクの交代・回復技」「アシレーヌのクイックターン」を試し、受け出し後に残るHPを記録。回す途中でHPが足りなくなる相手と、回せても倒せない相手を分けて調整します。現行v1.0は比較用として維持します。
