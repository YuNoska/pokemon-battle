[SerebiiのChampions図鑑](https://www.serebii.net/pokedex-champions/toxapex/)で確認したさいせいりょくは交代時に最大HPの約1/3を回復します。なみのりは攻撃手段、どくどくは削り、くろいきりは能力変化の解除、じこさいせいは居座る際の回復です。

### 育成・登録チェック

- [ ] 全6匹の持ち物・特性・性格補正・ポイント・4技を上の表に合わせる。持ち物は重複なし。
- [ ] ドヒドイデは**さいせいりょく**。ひとでなし・じゅうなんでは同じ回復サイクルにならない。
- [ ] 写真のロトムの**おにび→トリック**。スカーフ所持も確認する。
- [ ] 写真のサーフゴーの**H32/C26/D8→H22/C32/S12**。この構築の元設定はブラッキー案とは異なる。
- [ ] グソクは**とんぼがえり採用**。ブラッキー案のドリルライナーとは別設定。
- [ ] メガストーン2種の所持を確認。登録6匹には両方入れるが、基本はマンダかグソクの片方を選出する。

メガグソクはむし・はがねになり、メガ前のみず耐性を失い炎4倍になります。通常姿の画像から相性を判断しないこと。メガ前はききかいひで意図せず交代する可能性もあります。

物理への受け出しでドヒドイデが先に倒れる場合のみ、ずぶとい（防御↑・攻撃↓）・H32/B32/D2を比較候補とします。まず上の固定設定で記録を取り、別案を混ぜません。

## 交代先をどう決めるか

| ドヒドイデが呼ぶ攻撃・相手 | 交代先候補 | 注意 |
| --- | --- | --- |
| 電気技 | カバルドン | 相手の水・草・氷のサブウェポンを確認。電気無効だけで安全とは限らない |
| 地面技 | ボーマンダ／ヒートロトム | 岩・氷技や、ふゆうを無視する特性には注意 |
| エスパー技 | サーフゴー／メガグソクムシャ | 鋼の耐性を使う。グソクは**メガ前にはエスパー耐性がない** |
| サーフゴーなど毒が効かない相手 | ロトムなど攻撃役 | 毒や回復を繰り返して、わるだくみの隙を与えない |

逆に、カバが呼ぶ水技、鋼枠が呼ぶ炎技はドヒドイデの受け出し候補。ただし技の威力・相手の強化・残りHPを確認します。交代すれば回復する特性でも、出したターンに倒されたら回復できません。

## 基本選出

### 1. ドヒドイデ＋カバルドン＋ボーマンダ

**まず試す基本形。** 水・炎はドヒドイデ、電気はカバ、地面はマンダで補完し、毒・ステロで削ってマンダを通します。これはタイプ上の補完であり、相手の全技を受け切れる保証ではありません。

相手に鋼・毒などどくどくが効かないポケモンが多く、マンダも止められる場合は、この選出を避けます。ドヒドイデ＋カバの2匹だけでは崩す力が足りません。

### 2. ドヒドイデ＋ヒートロトム＋グソクムシャ

**交代技で攻撃を続けたい選出。** ロトムのボルチェン・グソクのとんぼから有利対面を作り、ドヒドイデで受けて引く。グソクのであいがしらを使い直す展開を狙います。

電気無効枠がいないため、相手のボルチェンを止められません。またロトムの高速ボルチェンでは、出した味方がそのターンの攻撃を受けます。

### 3. ドヒドイデ＋サーフゴー＋ボーマンダ

**回復と崩しを両立する選出。** ドヒドイデを止めに来る相手にサーフゴーのわるだくみ、物理受けが削れたらマンダの竜舞を狙います。電気への受け先は薄くなるため、相手次第でカバを優先します。

## インテレオン入りの、前に負けた6匹への対応

相手はゴリランダー／グソクムシャ／ボーマンダ／ブラッキー／インテレオン／ブリジュラス。れいとうビーム・ちょうはつはユーザー報告済み、水技は「ねらいうち？」で未確定。持ち物・特性・4技目・実際の選出は不明です。

**選出の出発点：ドヒドイデ＋ヒートロトム＋グソクムシャ。** ドヒドイデで水・氷への受け出し候補を確保し、ロトムを電気・炎の切り返し役として残す。グソクは交代と攻撃を担当します。この選出でもブリジュラスやマンダの型次第で苦しく、対策完成とは扱いません。

1. インテレオンへカバ・マンダを無理に合わせない。ドヒドイデも挑発を受けたら回復・毒・くろいきりが使えず、なみのりだけで押し切るのは難しい。
2. ドヒドイデから引く際は再生力を使う。ただしロトムへ水技を受けさせない。相手が補助技・交代をする局面か、味方が倒れた後などの安全な着地を探す。
3. スカーフロトムを安全に出せたら10まんボルトで圧力。相手のスカーフ・タスキ等は未確認なので先手・一撃を無条件に保証しない。高速水を処理する前にトリックでスカーフを渡さない。
4. メガグソクのであいがしらは補助の攻撃手段。相手の交代・まもる・残HPを見て使い、確定で倒せるとは扱わない。
5. 挑発水に同じ負け方が続くなら記録して再調整。この6匹にはゴリランダーがいないため、ブラッキー案の先制草技による対策は使えない。

## アシレーヌから替える代償

- **ドラゴン無効・フェアリー打点を失う。** ガブリアスなどへの水・妖の攻撃圧力も低下。鋼枠を残しても、地面技との打ち分けには注意。
- **クイックターン・アンコールを失う。** ドヒドイデは自分で交代技を使わず、通常交代で再生力を発動する。回復しながら交代できても、相手に自由な行動を与える場合がある。
- **毒とあくびが競合する。** 毒状態の相手は眠らせられない。毒で削る相手か、カバのあくびで流したい相手かを先に決める。
- **ステロ・まきびし、砂は残る課題。** ドヒドイデは接地した毒タイプなのでどくびしを回収できるが、他の設置技は除去しない。砂中はたべのこしの回復が相殺される。

まず10戦程度、「ドヒドイデが交代で回復できたか」「どの技で受けが崩れたか」「最後に相手を倒す役が残ったか」を記録。再生力が働いても勝ち筋が残らない場合は、受けをさらに増やさず攻撃枠を見直します。
