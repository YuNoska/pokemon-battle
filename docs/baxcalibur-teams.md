**基本：キュウコン → セグレイブ → パーモット**

- 雪下で壁を張り、交代・補助技の隙に剣舞。無理に毎回積まない。
- 再起はHP半分で復活。剣舞の上昇は消える。襷・連続技・挑発に注意。
- ウルガモスにはセグレイブ＋ラウドボーン＋アシレーヌの別選出。

### 再起を成功させる手順

1. 壁を使える相手ならキュウコン始動。相手が鋼技・挑発で強く圧力をかける場合は、壁への固執を避ける。
2. セグレイブを無傷に近い状態で出し、剣舞か即攻撃を選ぶ。積む前に倒される対面では攻撃する。
3. 倒された後にパーモットを出す。タスキが残り、連続技・先制技・挑発などで行動を止められないなら再起。復活しても剣舞の上昇は残らない。
4. 復活後すぐ安全に交代できるとは限らない。パーモットが倒されてから再登場させる等、被弾せず出す順番を考える。

パーモットのタスキはステロ・まきびしなどで崩れます。この案は除去技を採っていないため、再起の確実性を保証できません。でんこうそうげきは使用後に電気タイプを失い、そのまま連打できません。マッハパンチにはてつのこぶし補正が付きます。

回復役はラウドボーン・サーフゴーですが、基本の壁再起選出では出しません。「6匹に回復役がいる」と「毎試合回復で粘る」は別です。

**基本：エースバーン＋エンペルト＋セグレイブ**

- 回復重視：ブラッキー＋ロトム＋セグレイブ。願い事の受け渡しは被弾に注意。
- 水主体：ゴリランダー＋エンペルト＋セグレイブ。草場は味方の地震も半減。
- ウルガモスはスカーフで切り返す。炎技は等倍で、倒せるHPまで削る。

### サイクルの流れと弱点

エースバーンのとんぼがえり、エンペルトのクイックターン、ロトムのボルトチェンジで相手を確認してセグレイブを出します。願い事は即時回復ではなく、次ターンの交代先が相手の攻撃を受けるので、安全に受け渡せる場面だけ使います。

草場はセグレイブのじしんも接地相手に半減。ゴリランダーと一緒に選ぶなら、鋼への地震で倒す前に場の残りターンを確認。ウルガモスを受け切る枠はなく、エースバーンのスカーフは火力を上げません。舞った相手への処理に苦戦するならAのラウドボーン入りを優先します。
